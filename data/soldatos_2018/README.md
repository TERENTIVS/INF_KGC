# Soldatos et al. (2018) supplementary files

The three `Supplementary_File_*.txt` files in this directory are
reproduced from:

> **Soldatos, T.G., Dimitrakopoulou-Strauss, A., Larribere, L.,
> Hassel, J.C. and Sachpekidis, C. (2018).** *Retrospective Side
> Effect Profiling of the Metastatic Melanoma Combination Therapy
> Ipilimumab–Nivolumab Using Adverse Event Data.* Diagnostics, 8(4):
> 76. doi:10.3390/diagnostics8040076

Published under the **Creative Commons Attribution 4.0 International
(CC BY 4.0)** licence. The files are bundled here for reproducibility
of the external validation set used in §3.4 of the accompanying paper;
attribution remains with the original authors.

The Soldatos et al. corpus is loaded by the external-validation cells
of `supplement.ipynb` and by `INF_notebook_clean.ipynb`. Of the
associations in these supplementary files, 7,804 matched target–AE
pairings in the TSA graph and form the external test set reported in
§3.4 of the paper.
